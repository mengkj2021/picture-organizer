## 进入与筛选

- [ ] **EX-01** 已归档「打包导出」进入：TopAppBar「打包导出」；筛选行；预览；文件名；「开始打包」；「管理已打包」
- [ ] **EX-02** 无筛选：预览为全部已归档（未排除）
- [ ] **EX-03** 进筛选应用标签/日期等 → 返回：摘要更新（含拍摄/导入日 chip）；预览仅命中项
- [ ] **EX-04** 清除筛选：预览恢复为全部已归档（会话排除规则见下）

## 预览排除（F41）

- [ ] **EX-10** 小图右上角叉：从**本次**打包集合去掉该图，预览消失
- [ ] **EX-11** 叉掉后进筛选再回：排除**保留**
- [ ] **EX-12** pop 出本画面再进入：排除清空
- [ ] **EX-13** 改筛选后：不自动恢复已排除 id
- [ ] **EX-14** 剩余 0 张：「开始打包」不可用；有空态文案
- [ ] **EX-15** 打包中：叉不可用

## 输出文件名与打包（F42 / S7）

- [ ] **EX-20** 默认主名 `export_{yyyyMMdd}`；后缀只读 `.zip`
- [ ] **EX-21** 用户改过的 stem 会话内保留；改筛选会按 docs 清空覆盖
- [ ] **EX-22** 合法改名 →「开始打包」：**只生成一个** zip；内容=筛选 ∩ 预览剩余；可分享；落 `exports/`
- [ ] **EX-23** 主名为空或含非法字符 → Snackbar，不开始打包
- [ ] **EX-24** `exports/` 已有同名 → 自动 `_2` / `_3` 落盘
- [ ] **EX-25** 打包中：系统返回拦截；文件名输入禁用
- [ ] **EX-26** 打包进度可见；结果列表展示生成文件
