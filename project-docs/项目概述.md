# 项目概述

> **android 现状**：产品定位与形态（与实现一致）。未决 / 是否实现见 [`project-status/`](../project-status/)。分册索引见 [README.md](README.md)。

## 1. 定位

- 本地 **Android 图片管理 App**：浏览、分类、整理图片。
- 场景：按规则归类后，**直接操作私有目录中的真实文件**（复制导入、状态间移动、重命名、筛选后打成**单个** zip 导出）。
- 工程：仓库根 [`android/`](../android/)（Gradle root）。

## 2. 应用形态

- 单 Activity + Jetpack Compose；桌面端不在范围。
- 全程本地、**不联网**（Manifest 无网络权限；不参与云备份 / 设备间迁移，见 [图片存储管理.md](图片存储管理.md)）。

## 3. 源码注释约定

- `android/` **默认无注释**（含票号）；约束与坑写在 `project-docs/` 或票库。
- `@Suppress` 等编译注解保留；产品级说明以本文档为准。
