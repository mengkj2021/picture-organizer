# 图片详细画面 · 状态操作（F30）

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 / `image-detail/{imageId}` |
| 区域名称 | 状态操作 |
| 对应 UI | TopAppBar `actions` ·「更多」溢出菜单；删除确认 `AlertDialog` |

## 2. 功能清单

- [x] **F30**：TopAppBar「更多」→「移动到」各目标状态（不含当前状态）
- [x] **F30**：仅当前图 `status = 回收站` 时，「更多」内显示「删除」
- [x] **F30**：移动成功 → 跳转同状态缩略条中的下一张（无下一张则前一张）；同状态已无其他图 → 返回主画面一览
- [x] **Bug7**：若移走的是**进入详情时一览（当前 Tab 筛选后可见集）的最后一张**，即使同状态全量仍有其它图，也**返回主画面一览**（保留 Tab / 筛选）；一览仍有其它可选时沿用 F30（切下一张，顺序不变）
- [x] **F30**：删除须确认；成功后返回主画面一览
- [x] 待归档 / 已归档详情不出现删除入口

## 3. 用户操作

1. 点 TopAppBar「更多」
2. 选「移动到 → 〈目标状态〉」→ 改库 + 搬文件 → 自动切到同原状态剩余图中的下一张（或返回一览）；**Bug7**：原一览（筛选后）已移空则直接返回一览
3. （仅回收站）选「删除」→ 确认对话框 → 真删文件 + DB → 返回一览

## 4. UI 描述

- 「更多」：`MoreVert` IconButton + `DropdownMenu`
- 移动项文案：`移动到` + 目标状态显示名（与一览一致）
- 删除：确认后再执行；忙碌中菜单项禁用

## 5. 数据 / 事件

- `ImageDetailUiEvent.MoveTo(ImageStatus)` / `DeleteCurrent`
- `ImageRepository.moveItems` / `deleteItems`（与主画面同源）
- `ImageDetailUiEffect.NavigateBack`（无剩余同状态图 / **Bug7 一览移空** / 删除成功）
- **Bug7**：进入详情时由主画面下发「一览（当前 Tab 筛选后）可见总数」；仅作**返回判定**，不参与「下一张」选取
- **Bug7 sentinel**：可见总数 `0` = 未提供，退回 F30「同状态全量」判定；仅当 `>0` 且进入时一览只剩当前这一张时触发「移空即返回」
- **删除成功**：只发 `NavigateBack`，不先发 Snackbar（Channel 上消息挂起会挡住 pop）。移动成功则「返回」与「下一张 + 提示」二选一
