# 式样问答 · 细则

> 供 `prompts/问答_式样问答.md` ▶ include。**不改代码、不改文档**。  
> 读入口见 [`文档分层约定.md`](../../宪法/文档分层约定.md)；禁止通读。

1. **先读文档回答**
   - 选世界：真相 → `project-docs/` / `project-status/`；AI 流程 → `ai-workbench/` + `prompts/` + `shared/`
   - 入口：`project-docs/项目概述.md`；按问题选读架构 §2 / 路由 / 画面 / 核心流程 / 数据层 / 技术栈等
   - 是否实现 / 未决见 `project-status/阶段/*/待对应.md` 与票内状态；过程见相关票复盘
   - 能完整回答 → 直接答；标明路径与章节；「待定」如实说，不猜

2. **文档不足 → 按文档定位代码**
   - 用已读文档中的包名、类名、route、画面名、数据流节点，定点打开 `android/app/src/`（及同包相邻）
   - 禁止无文档线索扫全库
   - 冲突时注明「以代码为准」并给出路径；区分「文档已确认」与「由代码推断」

3. **仍无法回答**：说明缺什么，不编造

4. **只问答**：不提交改动、不实现功能、不顺手整理文档
