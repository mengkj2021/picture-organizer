# 常用语句（AI 协作提示词）

> 复制粘贴到 CodeBuddy / Cursor 对话中使用。
> **开发约定**：本项目全部代码由 AI 开发（Kotlin / Gradle / 文档），无人工编写代码。
> **默认流程**：文档先行 → 按 docs/画面/ 实现代码 → 用户 Review。
> 相关文档见 [`docs/`](../docs/)、维护约定见 [`shared/README.md`](README.md)。

```

## 五、Git 提交

### 5.1 仅文档提交

```
请按 提交注意事项.md 提交本次文档改动：
- 先用 git status / git diff 确认范围
- git add 指定文件（不要用 git add .）

## 七、快捷短语

| 场景 | 一句话 |
|------|--------|
| 本步只文档 | `本步只改 docs/，下一步再写代码` |
| 只改构建 | `只改 Gradle / 依赖` |
| 按文档写代码 | `按 docs/画面/xxx.md 实现代码` |
| 文档先行 | `文档先行，确认后再写代码` |
| 不要提交 | `改完不要 commit` |
| 确认后提交 | `改完后 commit，不要 push` |
| 读式样书 | `以 docs/项目式样说明书.md 为准` |
| 读路由 | `route 命名遵循 docs/路由设计.md` |
| 画面 SOP | `新画面流程见 docs/路由设计.md 第 4 节` |
