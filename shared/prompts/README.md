# prompts · 拉入执行模板

本目录存放「**只改填写区，拉进对话即可执行**」的提示词文件。

## 用法

1. 打开对应模板（如 `功能开发.md`）
2. 只改文末填写区
3. 把该文件拉进 Cursor / CodeBuddy 对话并发送

## 现有模板

| 文件 | 用途 |
|------|------|
| [功能开发.md](功能开发.md) | 按票执行：读票 → 拆票门槛 → 文档先行 → 步骤/档位确认 → 定点读码 → 实现 → 回写票与日志 |
| [式样问答.md](式样问答.md) | 问式样 / 规格：优先读 docs 回答；不足再定点读码（只问答不改代码） |
| [文档整理.md](文档整理.md) | 功能落地后：对照代码对齐全项目相关文档（默认只改文档） |
| [起票分析.md](起票分析.md) | 杂散需求 → 对照拆票门槛落盘：文档优先分析 → 按类型与序号建票（子票新号、关联母题）、登记台账（只建票不改码） |
| [交叉审查.md](交叉审查.md) | 双 AI 互审：按固定清单审 diff/票验收（可选工具，不进功能开发强制流程） |

## 新增模板约定

- 上半：固定 AI 流程（用户不用改）
- 下半：空白填写区（用户每次只改这里）
- 无需同步到 `.cursor/` / `.codebuddy/`（按需拉入对话即可）
