# 导入画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 导入画面 |
| route | `import-images` |
| 职责 | 从相册或文件选择器多选图片，按阈值压缩后写入 app 私有目录与 Room，导入过程展示 Loading |

## 2. 路由定义

- 路由字符串：`import-images`
- 必选参数：无
- 可选参数：无
- 参数说明：无

## 3. 功能清单

- [x] TopAppBar + 返回（无底部导航栏）
- [x] 「从相册选择」多选入口（Photo Picker）
- [x] 「从文件选择」多选入口（SAF）
- [x] 导入前按阈值压缩（>2MB 或长边 >1920px）
- [x] 写入 `filesDir/images/pending/` + Room（status=Pending）
- [x] 导入过程全屏 Loading
- [ ] 导入失败明细列表（后续可增强；本阶段 Snackbar / 简要错误）

## 4. 用户操作

1. 从主画面「待处理」Tab 点击「导入图片」进入本画面
2. 选择「从相册选择」或「从文件选择」，多选图片
3. 等待 Loading（压缩 + 落盘 + 写库）
4. 完成后自动返回主画面；新图出现在「待处理」列表

## 5. UI 描述

- 顶部：`TopAppBar`，标题「导入图片」，导航图标返回
- 主体：两个主操作按钮（相册 / 文件），垂直居中或靠上排列
- 无底部 NavigationBar
- 导入中：半透明遮罩 + `CircularProgressIndicator` + 进度文案（如「正在导入 2/5」）

## 6. 系统返回动作

| 场景 | 行为 |
|---|---|
| Idle | 返回键 / 返回箭头 = `popBackStack()` 回主画面 |
| 导入中 | `BackHandler` 拦截，不中断导入（或提示稍候） |

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | 主画面 · 待处理 ·「导入图片」 |
| 可前往 | 无（完成后返回） |
| 退出去向 | `popBackStack()` 回 `main` |

## 8. 数据依赖

- UI：`ImportScreen`；逻辑：`ImportViewModel`（`ImportUiState` / 事件）
- 工具：`AppFileManager`、`ImageManager`
- 持久化：`ImageRepository.insert` → Room；文件：`context.filesDir/images/pending/`
- 详见 [架构设计.md](../设计/架构设计.md)
