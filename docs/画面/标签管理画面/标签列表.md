# 标签管理 · 标签列表

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 标签管理（`tag-manage`） |
| 区域名称 | 标签列表 |
| 对应 UI | Tab「标签」+ LazyColumn |

## 2. 功能清单

- [x] 观察并展示全部标签（排序）
- [x] 添加（对话框输入名）
- [x] 编辑名称
- [x] 删除（确认）；**F8**：无引用直接删；有引用二次确认后清图片 `tagsJson` + Exif

## 3. 用户操作

1. 点添加 → 输入 → 保存
2. 点行编辑或删除（有引用时二次确认影响张数）

## 4. UI 描述

- FAB 或顶栏添加；行：名称 + 编辑/删除图标

## 5. 数据 / 事件

- `observeTags` / `insertTag` / `updateTag` / `deleteTag`
- F8：`ImageRepository.countImagesWithTag` / `removeTagFromAllImages`

## 6. 待定事项

- 无
