# 标签管理画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 标签管理画面 |
| route | `tag-manage` |
| 职责 | 维护标签库（`tags`）与标签模板（`tag_templates`） |

## 2. 路由定义

- 路由字符串：`tag-manage`
- 参数：无

## 3. 功能清单（总览）

- [x] 无底部 NavigationBar；TopAppBar + 返回
- [x] 双 Tab：标签列表 / 标签模板

| 区域 | 文档 |
|---|---|
| 标签列表 | [标签列表.md](标签列表.md) |
| 标签模板 | [标签模板.md](标签模板.md) |

## 4. 用户操作（总览）

1. 从设置进入
2. 在两 Tab 内增删改
3. 返回设置

## 5. UI 壳层

- 顶部：`TopAppBar`「标签管理」
- 主体：TabRow + 对应列表
- 无底栏

## 6. 系统返回动作

| 场景 | 行为 |
|---|---|
| 有上级 | `popBackStack()` → settings |

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | [设置画面](../设置画面/README.md) |
| 可前往 | 无 |
| 退出去向 | 回 `settings` |

## 8. 数据依赖

- `TagManageViewModel` + `TagRepository`（C4）
- 删库标签不改 `images.tagsJson`

## 9. 待定事项

- 无（详情选用已由 **C6** 完成）
