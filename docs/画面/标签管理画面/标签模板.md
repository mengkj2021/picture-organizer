# 标签管理 · 标签模板

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 标签管理（`tag-manage`） |
| 区域名称 | 标签模板 |
| 对应 UI | Tab「模板」+ 列表 / 编辑对话框 |

## 2. 功能清单

- [x] 展示模板名、包含的标签 Chip、是否默认
- [x] 添加 / 编辑：名称 + 多选库内标签
- [x] 设为默认（唯一）
- [x] 删除（确认）

## 3. 用户操作

1. 添加模板并勾选标签 → 保存
2. 设默认 / 编辑 / 删除

## 4. UI 描述

- 列表行；编辑用对话框或底部表单（名称 TextField + FilterChip 多选）

## 5. 数据 / 事件

- `observeTemplates` / `insertTemplate` / `updateTemplate` / `deleteTemplate` / `setDefaultTemplate`

## 6. 待定事项

- 无
