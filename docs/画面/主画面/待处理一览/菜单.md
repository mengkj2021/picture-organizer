| 项 | 内容 |

## 2. 功能清单

- [x] 编辑 / 完成
- [x] 「移动到」→ 已确认 / 回收站（编辑且有选中时，行内）
- [x] 「导入图片」→ `import-images`（右侧）
- [x] **筛选**：跳转 [`filter`](../../筛选画面/README.md)；返回后展示条件摘要 Chip；可清除
- [x] **F5**：「更多」溢出菜单含全选（仅编辑态）；删除在回收站 Tab

## 3. 用户操作

1. 点「编辑」进入编辑模式；「完成」退出并清空选中
2. 「更多」→「全选」勾选**当前页**列表项
3. 「移动到」选择目标状态，批量改库 + 搬文件
4. 「导入图片」进入导入画面
5. 「筛选」→ `filter`；应用后该 Tab 回到第 1 页并清空选中；摘要 Chip /「清除」展示当前条件

## 4. UI 描述

- 水平工具栏：编辑、（编辑态）移动到、筛选、更多；导入在右侧
- 有筛选时：工具栏下方 Chip 摘要（标签 / 未打标签 / 文件名关键字）+ 清除

## 5. 数据 / 事件

- `ToggleEditMode` / `SelectAll` / `MoveSelectedTo` / `ImportImages`
- `SetTagFilter` / `ClearTagFilter`（由筛选画面回传触发）
