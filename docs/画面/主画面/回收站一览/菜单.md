# 回收站一览 · 菜单

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面 · 回收站 Tab |
| 区域名称 | 菜单 |
| 对应 UI | `TabActionBar` + 筛选条件摘要（`MainTab.NoModify`） |

## 2. 功能清单

- [x] 编辑 / 完成
- [x] 「移动到」→ 待处理 / 已确认（编辑态行内）
- [x] **F5**：「更多」内全选 / 删除（删私有文件 + DB；需编辑且有选中）
- [x] **筛选**：跳转 [`filter`](../../筛选画面/README.md)；返回展示摘要；可清除

## 3. 用户操作

1. 编辑 →「更多」全选或删除
2. 或「移动到」改状态并搬文件
3. 「筛选」同待处理一览 · 菜单

## 4. UI 描述

- 筛选 icon + 更多（含删除）；有条件时 Chip 摘要

## 5. 数据 / 事件

- `DeleteSelected`（仅本 Tab）；`MoveSelectedTo`
- `SetTagFilter` / `ClearTagFilter`
