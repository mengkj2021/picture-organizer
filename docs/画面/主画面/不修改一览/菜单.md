# 不修改一览 · 菜单

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 主画面 · 不修改 Tab |
| 区域名称 | 菜单 |
| 对应 UI | `TabActionBar`（`MainTab.NoModify`） |

## 2. 功能清单

- [x] 编辑 / 完成、全选
- [x] 「移动到」→ 待处理 / 已确认
- [x] 「删除」— 删私有文件 + DB 行（需有选中）

## 3. 用户操作

1. 编辑勾选后「删除」真实删除
2. 或「移动到」改状态并搬文件

## 4. UI 描述

- 右侧专属「删除」按钮

## 5. 数据 / 事件

- `DeleteSelected`（仅本 Tab）；`MoveSelectedTo`
