# 主画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 主画面 |
| route | `main` |
| 职责 | App 主界面：标题栏 + 底部三 Tab，按整理状态展示分类一览 |

## 2. 路由定义

- 路由字符串：`main`
- 必选参数：无
- 可选参数：无
- 参数说明：Tab 切换为本地状态，不单独注册 route

## 4. 用户操作（壳层）

1. 从启动画面自动进入
2. 点击标题栏设置进入设置画面
3. 点击底部 Tab 切换三个一览
4. 各 Tab 内操作见对应「菜单 / 一览」文档

## 5. UI 壳层

- 顶部：Material 3 `TopAppBar`，标题「图片整理」；右侧设置 icon
- 主体：当前 Tab 的 `ImageListTab`（菜单 + 列表）
- 底部：`NavigationBar` 三个 `NavigationBarItem`
