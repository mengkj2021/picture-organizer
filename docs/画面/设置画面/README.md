# 设置画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 设置画面 |
| route | `settings` |
| 职责 | App 设置入口（本阶段极简：仅「标签管理」） |

## 2. 路由定义

- 路由字符串：`settings`
- 必选 / 可选参数：无

## 3. 功能清单

- [x] TopAppBar + 返回
- [x] 列表项「标签管理」→ `tag-manage`
- [ ] 重命名模板 / 默认标签 / 教程等（完整 C9 后续）

## 4. 用户操作

1. 主画面标题栏设置 icon 进入
2. 点击「标签管理」进入标签管理画面
3. 返回主画面

## 5. UI 描述

- 顶部：`TopAppBar`「设置」+ 返回
- 主体：`ListItem` 一行「标签管理」

## 6. 系统返回动作

| 场景 | 行为 |
|---|---|
| 有上级 | `popBackStack()` |

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | [主画面](../主画面/README.md) TopAppBar 设置 |
| 可前往 | [标签管理画面](../标签管理画面/README.md) |
| 退出去向 | 回 `main` |
