# 图片详细画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 图片详细画面 |
| route | `image-detail/{imageId}` |
| 职责 | 单张图片浏览（缩放）、重命名、标签增删改；底部同状态缩略条切换 |

## 2. 路由定义

- 路由字符串：`image-detail/{imageId}`
- 必选参数：`imageId`（图片主键）
- 可选参数：无
- 参数说明：进入后按 id 读库得到 `status`；缩略条仅展示同一 `status` 下的列表

## 3. 功能清单

- [x] 无底部 NavigationBar
- [x] 主图显示（Coil 加载私有目录文件）+ pinch 缩放
- [x] 文件重命名（同目录改名 + 更新 DB）
- [x] 标签添加 / 删除 / 修改（Room `tagsJson` + Exif `UserComment` 双写）
- [x] 底部横向滚动缩略图条（仅当前状态）；点击切换当前图
- [x] TopAppBar 返回 / 系统返回 → `popBackStack`

## 4. 用户操作

1. 主画面非编辑模式点击列表项进入本画面
2. 双指捏合放大 / 缩小主图
3. 编辑文件名并确认保存（校验空名、非法字符、同目录重名）
4. 添加标签、删除 Chip、编辑已有标签后保存
5. 底部缩略条滚动并点击切换到同 Tab 另一张图
6. 返回主画面

## 5. UI 描述

- 顶部：`TopAppBar`，导航图标返回；标题为当前文件名
- 主体上部：可缩放主图区域（占主要高度）
- 主体中部：重命名输入行 + 确认按钮；标签 FlowRow（可删）+ 添加 / 编辑入口
- 底部：`LazyRow` 缩略图条，当前项描边高亮；无底部导航栏

## 6. 系统返回动作

| 场景 | 返回键 / 返回箭头行为 |
|---|---|
| 有上级画面 | `popBackStack()` 回主画面 |
| 重命名 / 标签编辑中未保存 | 不强制拦截（以已确认提交为准）；待定可后续加 |

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | 主画面三 Tab 列表项点击（非编辑模式） |
| 可前往 | 无（本阶段） |
| 退出去向 | 返回主画面 |

## 8. 数据依赖

- **MVVM**：`ImageDetailScreen` / `ImageDetailViewModel`（`ImageDetailUiState` / `ImageDetailUiEvent` / `ImageDetailUiEffect`）
- **Repository**：`observeItem` / `observeItems(status)` / `rename` / `updateTags`
- **文件**：`AppFileManager.renameInPlace`；标签文件侧：`ImageTagMetadata`（Exif `TAG_USER_COMMENT` JSON）
- **UI 模型**：`ImageListItem` 含 `filePath`（相对 `images/`）
- Coil 加载 `filesDir/images/{filePath}`
