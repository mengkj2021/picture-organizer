# 图片详细画面 · 主图缩放

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 |
| 区域名称 | 主图缩放 |
| 对应 UI | Coil `AsyncImage` + `detectTransformGestures` / tap |

## 2. 功能清单

- [x] 按 `filePath` 加载私有目录图
- [x] 双指 pinch 缩放（约 1x～5x）与平移
- [x] 双击重置缩放（恢复 1x、居中）
- [x] **F4**：scale>1 时默认隐藏重命名/标签区；单击主图切换强制显示

## 3. 用户操作

1. 捏合放大/缩小；切换缩略条图片时重置缩放
2. 双击主图恢复 1x（并居中）
3. 放大后单击主图：显示/隐藏下方编辑区

## 4. UI 描述

- 占主体主要高度；`ContentScale.Fit`；缩略条始终保留

## 5. 数据 / 事件

- `ImageDetailViewModel.absoluteFile(item)`

## 6. 待定事项

- 无
