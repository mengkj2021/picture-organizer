# 图片详细画面 · 重命名

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 |
| 区域名称 | 重命名 |
| 对应 UI | 文件名 `OutlinedTextField` + 确认按钮 |

## 2. 功能清单

- [x] 同目录改物理文件名 + 更新 DB（`fileName` / `filePath` / `description`）
- [x] 校验空名、非法字符、同目录重名；未写扩展名时保留原扩展名
- [x] 套用重命名模板（`{name}` `{date}` `{tag}`，保留扩展名）

## 3. 用户操作

1. 编辑文件名 → 「重命名」保存；失败 Snackbar
2. 「套用重命名模板」选择模板后立即重命名

## 4. UI 描述

- 「文件名」标题 + 输入行 + 按钮
- 「套用重命名模板」下拉（无模板时禁用）

## 5. 数据 / 事件

- `SaveRename` → `repository.rename`
- `ApplyRenameTemplate` → `RenamePatternApplier` + `rename`
