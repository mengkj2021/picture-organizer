# 图片详细画面 · 标签

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 图片详细画面 |
| 区域名称 | 标签 |
| 对应 UI | 用户标签 Chip + 标签库多选 + 套用模板 + 自由输入 |

## 2. 功能清单

- [x] 添加 / 删除 / 修改用户标签（不含状态标签）
- [x] Room `tagsJson` 真源；同步 Exif `UserComment` JSON
- [x] Exif 失败时 DB 仍成功，Snackbar 提示
- [x] 从标签库多选 Chip（**C6 · 1A**）；保留自由输入
- [x] 套用标签模板：模板名列表合并进当前用户标签、去重（**C6 · T2**）

## 3. 用户操作

1. 点标签库 Chip：已有则移除，没有则加入并保存
2. 非库内自定义标签：Chip 编辑 / 关闭删除；下方输入框新增或改名
3. 「套用模板」选模板 → 合并标签名后保存
4. 不改重命名模板（**R1**，见 C9）

## 4. UI 描述

- 标题「标签」
- FlowRow：标签库 `FilterChip`（选中=已在本图）
- FlowRow：不在库内的自定义 `InputChip`（编辑 / 删除）
- 「套用模板」按钮 + 菜单（无模板时禁用或提示）
- 输入框 + 保存 / 取消

## 5. 数据 / 事件

- `ToggleLibraryTag` / `ApplyTemplate` / `SaveTag` / `DeleteTag` → `repository.updateTags` + `ImageTagMetadata`
- `TagRepository.observeTags` / `observeTemplates`
