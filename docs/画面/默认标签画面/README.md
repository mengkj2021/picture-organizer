# 默认标签画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 默认标签 |
| route | `default-tags` |
| 职责 | 选择导入时自动打上的库标签（多选） |

## 2. 路由定义

- 路由字符串：`default-tags`
- 参数：无

## 3. 功能清单

- [x] 展示库标签 Checkbox 多选
- [x] 保存到 DataStore；仅**新导入**生效

## 4. 用户操作

1. 设置 → 本画面 → 勾选 → 保存/返回时写入
2. 之后导入的图片自动合并这些用户标签

## 5. UI 壳层

- TopAppBar + 保存；主体可滚动 Checkbox

## 6. 系统返回动作

| 场景 | 行为 |
|---|---|
| 有上级 | `popBackStack()`（未点保存则不写入，或自动保存——实现为点「保存」） |

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | [设置画面](../设置画面/README.md) |
| 退出去向 | 回 `settings` |

## 8. 数据依赖

- `TagRepository.observeTags()`；`UserPreferencesRepository` 默认标签名集合
