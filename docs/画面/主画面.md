# 主画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 主画面 |
| route | `main` |
| 职责 | App 主界面：标题栏 + 底部三 Tab 切换，按整理状态展示图片分类列表 |

## 2. 路由定义

- 路由字符串：`main`
- 必选参数：无
- 可选参数：无
- 参数说明：Tab 切换使用本地状态，不单独注册 route

## 4. 用户操作

1. 从启动画面自动进入本画面
2. 点击底部 Tab 切换「待处理 / 已确认 / 不修改」一览
3. 滚动浏览当前 Tab 下的假数据列表
4. 点击「编辑」进入编辑模式，勾选列表项或「全选」
5. 「移动到」下拉选择目标状态，批量改状态（假数据跨 Tab 移动）
6. 点击「完成」退出编辑模式
7. 待处理 Tab：「导入图片」；不修改 Tab：「删除」（本阶段 Snackbar 提示功能开发中）

## 5. UI 描述

- 顶部：Material 3 `TopAppBar`，标题为应用名称「图片整理」
- 列表上方：`TabActionBar` 水平工具栏
  - 通用：编辑 / 完成、全选、移动到（下拉另两个状态）
  - 待处理专属：导入图片（右侧）
  - 不修改专属：删除（右侧）
- 主体：当前 Tab 对应的 `LazyColumn` 列表；编辑模式下每项左侧 Checkbox
- 列表项布局（单行）：
  - 左侧：72dp 彩色占位块 + 图片图标（假缩略图）
  - 右侧：日期（次要色小字）、描述（单行省略）、标签（1～2 个 AssistChip）
- 底部：`NavigationBar` 含三个 `NavigationBarItem`：
  - 待处理一览
  - 已确认一览
  - 不修改一览

## 8. 数据依赖

- **MVVM 分层**（详见 [架构设计.md](../架构设计.md)）
  - UI：`MainScreen` + `ui/main/tab/` 纯 Composable（只读 State、发送 Event）
  - 逻辑：`MainViewModel`（`MainUiState` / `MainUiEvent` / `MainUiEffect`）
  - 数据：`ImageRepository` ← `MockImageRepository`（内存假数据，种子来自 `MockImageListData`）
- **Room（已建库，本画面仍读 Mock）**
  - `PictureOrganizerApplication` → `AppDatabase`（`picture_organizer.db`）
  - `ImageEntity` / `ImageDao` 已定义，尚未接入 Repository
- **后续**：`RoomImageRepository` 替换 Mock；`AppFileManager` / `ImageManager` 实现导入与压缩
