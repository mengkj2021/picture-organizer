# 主画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 主画面 |
| route | `main` |
| 职责 | App 主界面：标题栏 + 底部三 Tab 切换，按整理状态展示图片分类列表 |

## 2. 路由定义

- 路由字符串：`main`
- 必选参数：无
- 可选参数：无
- 参数说明：Tab 切换使用本地状态，不单独注册 route

## 3. 功能清单

- [x] 顶部标题栏（TopAppBar，显示应用名称「图片整理」）
- [x] 底部导航栏（NavigationBar，三个 Tab）
- [x] Tab「待处理 / 已确认 / 不修改」— Room 持久化列表（Flow）
- [x] 列表项 UI：占位缩略图 + 日期 + 描述 + 标签
- [x] 列表上方操作栏（TabActionBar）：编辑 / 全选 / 批量改状态
- [x] 编辑模式：列表项 Checkbox、批量移动到另外两个状态（持久化）
- [x] 待处理 Tab：「导入图片」→ 导航至 `import-images`
- [x] 不修改 Tab：「删除」— 删私有文件 + DB 行
- [x] 「移动到」— 改库 + 搬到对应子目录
- [ ] 列表项真实缩略图（后续）

## 4. 用户操作

1. 从启动画面自动进入本画面
2. 点击底部 Tab 切换「待处理 / 已确认 / 不修改」一览
3. 滚动浏览当前 Tab 下的图片列表（初始可为空）
4. 点击「编辑」进入编辑模式，勾选列表项或「全选」
5. 「移动到」下拉选择目标状态，批量改状态（Room 持久化）
6. 点击「完成」退出编辑模式
7. 待处理 Tab：「导入图片」进入导入画面；不修改 Tab：勾选后「删除」真实删除文件与记录

## 5. UI 描述

- 顶部：Material 3 `TopAppBar`，标题为应用名称「图片整理」
- 列表上方：`TabActionBar` 水平工具栏
  - 通用：编辑 / 完成、全选、移动到（下拉另两个状态）
  - 待处理专属：导入图片（右侧）
  - 不修改专属：删除（右侧）
- 主体：当前 Tab 对应的 `LazyColumn` 列表；编辑模式下每项左侧 Checkbox
- 列表项布局（单行）：
  - 左侧：72dp 彩色占位块 + 图片图标
  - 右侧：日期（次要色小字）、描述（单行省略）、标签（1～2 个 AssistChip）
- 底部：`NavigationBar` 含三个 `NavigationBarItem`

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | `splash` 启动画面自动跳转 |
| 可前往 | `import-images` 导入画面 |
| 退出去向 | 退出应用 |

## 8. 数据依赖

- **MVVM 分层**（详见 [架构设计.md](../架构设计.md)）
  - UI：`MainScreen` + `ui/main/tab/` 纯 Composable
  - 逻辑：`MainViewModel`（`MainUiState` / `MainUiEvent` / `MainUiEffect`）
  - 数据：`ImageRepository` ← `RoomImageRepository`（Flow）；文件在 `images/{pending,confirmed,no_modify}/`
- Mock 仅用于 Compose Preview
