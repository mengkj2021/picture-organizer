# 导入画面 · 来源选择

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 导入画面（`import-images`） |
| 区域名称 | 来源选择 |
| 对应 UI | 压缩开关 + 相册 / 文件按钮 |

## 2. 功能清单

- [x] 「按规则压缩」开关（默认开；DataStore 记住）+ 规则说明
- [x] 「从相册选择」多选（Photo Picker）
- [x] 「从文件选择」多选（SAF）
- [x] **F3**：提示「同一张图重复导入会生成另一条记录」

## 3. 用户操作

1. （可选）切换是否压缩
2. 点选相册或文件 → 开始导入

## 4. UI 描述

- 上方：重复导入提示 + 开关 + 说明（>2MB 或长边 >1920 → JPEG 85）
- 下方：两按钮垂直排列

## 5. 数据 / 事件

- `compressEnabled` ↔ DataStore；Activity Result → `importUris`

## 6. 待定事项

- 无
