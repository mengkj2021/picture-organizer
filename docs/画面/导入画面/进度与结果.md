# 导入画面 · 进度与结果

## 1. 区域概述

| 项 | 内容 |
|---|---|
| 所属画面 | 导入画面（`import-images`） |
| 区域名称 | 进度与结果 |
| 对应 UI | 全屏 Loading 遮罩 + Snackbar |

## 2. 功能清单

- [x] 压缩开：超阈值则压缩（>2MB 或长边 >1920 → JPEG 85）；未超保留原样
- [x] 压缩关：**原样复制**，不压缩
- [x] 写入 `images/pending/` + Room（Pending）；合并默认标签
- [x] 进度文案「正在导入 x/y」
- [x] 全部成功：返回主画面
- [x] 部分/全部失败：失败明细弹窗（文件名 + 原因），支持单张/全部重试

## 3. 用户操作

1. 选择完成后等待；成功自动返回；失败可再选或返回

## 4. UI 描述

- 导入中：半透明遮罩 + `CircularProgressIndicator` + 进度文字
- 导入结束若有失败：AlertDialog 失败明细（文件名 + 原因分类 + 原始信息），每行「重试」，底部「全部重试」/「完成」

## 5. 数据 / 事件

- `ImageManager.prepareForImport(uri, compressEnabled)`；`repository.insert`
- 失败明细：`ImportUiState.failedItems`（`FailedImportItem`：uri / displayName / errorKind / errorDetail）；`ImageManager.displayNameOf(uri)`
- 重试：`retryItem(uri)` / `retryAll()` / `dismissFailures()`；全部成功后发 `ImportUiEffect.ImportFinished`
