# 画面 · 文档索引

一层目录 = 一个 route 画面；目录内按 **UI 区域** 拆文件（从文件名定位）。路由表 / 式样书链到各目录 **`README.md`（总览）**。

| 目录 | route | 说明 |
|------|-------|------|
| [启动画面/](启动画面/) | `splash` | 简单画面，仅 README |
| [主画面/](主画面/) | `main` | 壳 + 列表项 + 三 Tab「菜单 / 一览」 |
| [导入画面/](导入画面/) | `import-images` | 来源选择、进度与结果 |
| [图片详细画面/](图片详细画面/) | `image-detail/{imageId}` | 主图、重命名、标签、缩略条 |
| [设置画面/](设置画面/) | `settings` | 极简设置（当前仅标签管理入口） |
| [标签管理画面/](标签管理画面/) | `tag-manage` | 标签库 + 标签模板 |
| [_模板/](_模板/) | — | 新建画面时复制整目录 |

## 新增画面

1. 复制 `_模板/` → `画面名/`
2. 填写 `README.md`，按需加区域文件（参考 `_模板/区域模板.md`）
3. 登记 [`docs/设计/路由设计.md`](../设计/路由设计.md) 第 3 节
4. 更新 [`docs/式样/项目式样说明书.md`](../式样/项目式样说明书.md) 第 5 章
5. 再实现代码

详见 [`docs/README.md`](../README.md)。
