# 启动画面

## 1. 画面概述

| 项 | 内容 |
|---|---|
| 画面名称 | 启动画面 |
| route | `splash` |
| 职责 | App 启动后的首个画面，当前仅展示应用名称，后续作为功能入口 |

## 2. 路由定义

- 路由字符串：`splash`
- 必选参数：无
- 可选参数：无

## 3. 功能清单

- [x] 显示应用名称（当前为静态文字）
- [x] 启动后自动导航至 `main` 主画面

## 4. 用户操作

1. 打开 App 进入本画面
2. 短暂展示后自动跳转至主画面（无需用户操作）

## 5. UI 描述

- 主体：居中显示应用名称（`headlineMedium` 标题样式）
- 背景：Material 3 主题默认背景，edge-to-edge 全屏

## 6. 系统返回动作

| 场景 | 行为 |
|---|---|
| splash 展示期间 | 返回键退出应用（系统默认） |
| 跳转至 main 后 | splash 不在 back stack；main 为应用根画面，返回键退出应用 |

## 7. 进入与退出

| 方向 | 说明 |
|---|---|
| 从哪里进入 | App 启动（MainActivity） |
| 可前往 | `main` 主画面（自动跳转） |
| 退出去向 | 跳转后 splash 不在 back stack |

## 8. 数据依赖

- 无（当前静态展示）
