## 1. 项目概述与定位

- 目标：开发一款**图片管理软件**（App 或桌面软件），用于浏览、分类并整理图片文件。
- 用户场景：把收集 / 拍摄的图片按规则归类，**直接操作文件夹**整理真实文件。
- 三步规划进度：

| 步骤 | 内容 | 状态 |
|------|------|------|
| 1 | AI 开发目录搭建 | ✅ 已完成 |
| 2 | 项目式样准备 | 🔄 进行中（本文档） |
| 3 | 基础项目搭建与开发 | 🔄 进行中（主画面 UI + MVVM + Room 架子已完成） |

- **全部代码由 AI 开发**（Kotlin 业务、Compose UI、Gradle 配置）；用户负责需求确认、Review 与验收。
- **默认流程**：文档先行（`docs/画面/` → 路由表 → 式样书第 5 章），再按文档实现代码。

- 包结构、数据流、Room 表设计详见 [架构设计.md](架构设计.md)

## 4. 核心功能（已确认）

- 图片处理流程：**导入 → 压缩保存 → 单张图片操作 → 按标签分类导出**

### 4.1 导入

- 图片需用户**手动导入**到 app 私有目录（复制，非移动）
- 导入来源支持两种：**系统相册 / 图库** 与 **文件选择器**

### 4.2 导入时压缩

- 判断标准：**文件大小或像素分辨率任一超过阈值即压缩**（两者结合判断），未超阈值保留原样
- 压缩阈值具体数值：待定（后续细调）

### 4.3 单张图片操作（当前阶段）

- 支持：**重命名**、**加标签**、**确认设置完成**（确认完成也是一个标签）
- 剪切：不纳入当前阶段，列为以后扩展

### 4.4 按标签分类导出

- 按标签将已整理图片分组，**每个标签单独生成一个压缩包（zip）**，存入 app 私有目录
- 用户通过系统文件管理器或分享功能自行拷出至外部目录（App 内是否提供导出入口：待定）

## 6. 文件整理方案（已确认）

- 整理方式：**直接操作文件夹** —— 移动 / 重命名真实文件，按规则归类。
- 图片统一存放在 **app 私有目录**，由用户手动导入（复制）进入
- 导入时按需压缩后保存到私有目录
- 按标签分类后，每个标签单独打包为 zip，存入 app 私有目录；用户通过系统文件管理器或分享功能自行拷出
- 全程本地运行，**不联网**，无网络权限需求
