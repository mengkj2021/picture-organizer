# 开发日志 · 2026-09-02 Bug1 教程画面系统栏裁切修复

## 问题

高版本 Android（edge-to-edge）上教程画面上下被系统栏 / 安全区裁切：顶部「跳过」顶进状态栏区，底部「下一步 / 开始使用」被导航条遮挡。

## 成因

- `MainActivity` 调用 `enableEdgeToEdge()`，内容默认延伸到系统栏之下。
- 项目内普通画面均套 M3 `Scaffold`（自动消费系统栏 inset）；唯独 `TutorialScreen` 为裸 `Column` + 固定 16dp padding，未处理 inset。

## 改动

- `app/src/main/java/com/pictureorganizer/ui/tutorial/TutorialScreen.kt`
  - 外层 `Column` → M3 `Scaffold`（无 topBar / bottomBar），content 应用 `innerPadding`（系统栏 inset）后再叠原 16dp padding
  - 顶部「跳过」、`HorizontalPager`、页指示、底部按钮结构不变，仅随 inset 内缩
- 其他画面与逻辑零改动（1 文件）

## 验收

- API 30+（手势导航 / 挖孔屏）首次进入教程：顶部「跳过」不被状态栏遮挡；底部页指示 + 按钮完整显示在导航条之上
- 设置 →「查看教程」路径同样正常，返回行为不变
- 3 页滑动 / 跳过 / 开始使用行为不变
