## 用户诉求 / 场景

- 要解决的问题或场景：一览列表每页固定 30 条、分页不可关；图多时翻页烦，图少时「每页 30」也要翻页，用户希望自己定
- 预期效果：设置里可「关闭分页」（一次看全当前筛选结果）或调整每页数量；默认保持现状（开分页、30 条），老用户无感
- 是否已有式样依据：否（C3 硬编码每页 30 的体验调整）

## 需求确认（接票前若为「待定」先在此澄清）

建议默认（可先按此实施）：

- **存放**：`UserPreferencesRepository`（DataStore，与 `import_compress_enabled` 同风格）加 `list_paging_enabled`（默认 true）+ `list_page_size`（默认 30）
- **设置页 UI**：「列表」组加两行——开关「分页显示」；每页数量单选（20 / 30 / 50 / 100，仅分页开启时可选，关闭时置灰或隐藏）
- **主画面**：一览分页逻辑读偏好——关闭分页 = 不分页切片，隐藏页码栏，「全选」作用于当前筛选全部；开启 = 现状（切片 + 页码 + 全选当前页）
- 排序 / 筛选条件不变；每页数量变更即时生效或回到第 1 页（默认：回到第 1 页）
- 范围：只影响主画面三一览列表；打包 / 筛选结果集逻辑不变
