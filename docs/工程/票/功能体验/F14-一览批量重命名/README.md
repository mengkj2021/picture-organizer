## 用户诉求 / 场景

- 要解决的问题或场景：目前重命名只能进详情逐张操作（手输或套模板）；批量改名（如按模板统一日期 / 前缀整理一批）无入口
- 预期效果：主画面一览「编辑」勾选多张后，可一次套用重命名模板批量改名，不用逐张进详情
- 是否已有式样依据：部分（详情单张套模板为 C9；批量是新增）

## 需求确认（接票前若为「待定」先在此澄清）

建议默认（可先按此实施）：

- **入口**：三一览（待处理 / 已确认 / 回收站）编辑态 + 选中 ≥ 1 时，工具栏「移动到」旁出现「重命名」行内操作（放「更多」溢出菜单内亦可，接票定 UI，优先显式可见）
- **交互**：点「重命名」→ 弹模板选择（复用 `rename_templates` 列表，无模板时禁用并提示去设置建模板）→ 应用到全部选中项 → 完成
- **展开规则**：逐张套 `RenamePatternApplier`——`{name}` 各自原名、`{date}` 各自日期、`{tag}` 各自首个用户标签（与详情语义一致）；扩展名锁定（沿用 F2，不改后缀）
- **冲突处理**：同目录重名 / 非法名等失败项**不整体回滚**，逐张跳过并弹失败明细（仿 P1：单张 / 全部重试），成功项正常改名
- 范围不含：手输统一新名的批量替换模式（本期只做「套模板」一种批量方式）
