## 用户诉求 / 场景

- 要解决的问题或场景：图库缺乏「拍摄时间」维度——现在 `{date}` 占位符、排序用的都是**导入日期**（`ImageListItem.date` 由 `importedAt` 格式化），照片实际拍摄时间丢失。用户希望导入、筛选、重命名三处都能用拍摄日期
- 预期效果：① 导入时记录拍摄日期（照片 Exif `DateTimeOriginal`）；② 筛选画面可按拍摄日期排序 / 筛区间；③ 重命名模板 `{date}` 优先展开为拍摄日期
- 是否已有式样依据：否（新增能力；筛选画面待定 §9 明确「日期区间筛选不在本期」——本期落地，需同步该待定项）

## 需求确认（接票前若为「待定」先在此澄清）

建议默认（可先按此实施，异常处回票确认）：

- **数据底座**：`ImageEntity` 加 `dateTakenMillis: Long?`；`ImageListItem` 加对应字段；Room v3 → v4 + `MIGRATION_3_4`（旧行 null）
- **读取时机**：导入**压缩前**从来源读取 Exif `DateTimeOriginal`（压缩 / 重编码可能剥离 Exif），JPEG 无该标签或读取失败 → null（不伪造，UI 显示「拍摄日期未知」）
- **重命名 `{date}`**：改由「拍摄日期优先，无则回退现有导入日期」展开——模板既有数据行为不变，空档不产生空文件名；重命名模板管理画面占位符说明同步
- **筛选**：排序加入「拍摄日期 新→旧 / 旧→新」两档（null 排最后）；新增拍摄日期区间筛选（起止日期选择，null 不命中）
- **导入结果**：导入成功明细 / 列表项可显示拍摄日期（范围可选：先做到详情可看，列表不加列防拥挤）
- 排序字段仍保留 F6 已有「导入日期 / 文件名」选项，不冲突
