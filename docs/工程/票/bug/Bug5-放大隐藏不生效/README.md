## 现象（用户可观察）

1. 复现步骤：详情画面打开图片 → 双指放大（已明显大于 1x）→ 观察文件名（顶栏）/ 标签区。
2. 实际结果：**有时放大到超过 1x 了，文件名、标签仍不消失**；整体"动作也有点怪"（放大 / 单击唤出 / 双击复位的触发时机不稳定，隐藏与显示跟手不够自然）。
3. 期望结果：按 F4 语义——scale>1 即默认隐藏文件名/标签，缩回 1x 恢复；单击唤出、双击复位各就各位，无"该藏没藏"。

## 影响范围

- 涉及画面 / route：图片详细画面 `image-detail/{imageId}`（主图缩放 + 顶栏 + 重命名/标签区）
- 涉及数据或文件：无（纯 UI 状态问题，怀疑缩放状态与隐藏状态不同步）

## 根因（调查后填）

- 初步判断（待验证）：F4 的"隐藏"依赖 scale 判定或"强制显示"标记——可能路径：① 放大瞬间 scale 判定时机（瞬时值 / 未做阈值或 debounce）错过切换；② 此前单击过主图置了"强制显示"标志，后续放大不解除，导致"放大了也不藏"；③ tap（单击唤出）与缩放手势（detectTransformGestures / 双击）竞争，动作判定互相干扰。
- 定位证据（版本 / 截图 / 日志）：待复现补录（无截图工具，以复现步骤 + 代码路径为准）
