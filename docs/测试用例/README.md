# 测试用例 · 文档索引

> 手工验收用例，**按画面对齐** [`docs/画面/`](../画面/)。真相源仍是画面规格与式样书；本目录只写可执行步骤与预期，不另立需求。
>
> 新建画面用例：复制 [`_模板/`](_模板/) → 重命名为与画面同名的 `.md` → 填表 → 在本 README 登记。

## 约定

| 项 | 说明 |
|---|---|
| 编号 | `TC-<短码>-NN`（如 `TC-main-01`）；跨流程用 `TC-flow-NN` |
| 结果列 | ☐ 未测 ／ ✅ 通过 ／ ❌ 失败（失败可另起 [Bug 票](../工程/票/bug/)） |
| 范围 | 已确认式样与已实现功能；「待定」不写进必测项 |
| 环境 | 真机或模拟器；建议覆盖 **minSdk 26** 与较新系统（含手势导航 / 挖孔） |

短码与 route 对应见下表「用例文件」。

## 建议验收顺序

1. [跨画面流程.md](跨画面流程.md)（冒烟）
2. 启动 → 教程 → 主画面 → 导入 → 详情
3. 筛选 / 打包 / 设置系（标签、重命名模板、默认标签）
