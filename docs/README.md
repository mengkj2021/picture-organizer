## 文档与代码对齐约定

- **真相源**：`android/app/src/main`（及 `android/gradle/libs.versions.toml`）。文档与代码冲突时，改文档或先确认再改代码。
- **产品完成度**：C1–C10 已落地；未决体验项见改动清单 **P**，勿写入式样「已确认」章。
- **整理入口**：[`shared/prompts/文档整理.md`](../shared/prompts/文档整理.md)

## 新增画面流程（摘要）

1. 复制 `画面/_模板/` → `画面/xxx画面/`
2. 在 `设计/路由设计.md` 第 3 节登记 route（文档列指向 `画面/xxx画面/README.md`）
3. 更新 `式样/项目式样说明书.md` 第 5 章画面清单
4. 再实现 `android/app/src/...`（详见 `shared/rules/dev-convention.md`）

## 提示词

功能开发 / 起票分析 / 式样问答 / 文档整理见 [`shared/prompts/`](../shared/prompts/)。
